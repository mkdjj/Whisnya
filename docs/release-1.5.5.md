# Whisnya v1.5.5

## 更新内容

- 重做演绎的新建故事界面：故事、演员、篇幅与模型分区展示，预算和资料导入收进“更多设置”；演员卡片点击后编辑头像、人设和独立模型。
- 新故事的演员 A 默认使用用户设定作为主角，可添加演员 B、C 等，支持 1–26 位演员轮转；已有故事保持原演员顺序。手动接管、导出和回忆册按实际用户身份处理。
- API 设置一点直达，移除多余的分类中间页。
- 移除 QQ 接入、Android 后台服务和本地 Bridge，不删除现有聊天数据。
- 缩小气泡操作按钮，重新生成改为直接点击并放在操作栏左侧；调整输入工具栏、编辑重发与键盘交互。
- 统一主题底色，修复透明页面黑底及背景层遮住列表点击反馈的问题。
- 精简共用 AI 请求、总结与外观设置代码，移除旧迁移逻辑和旧自动测试代码。
