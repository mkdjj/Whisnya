# 故事演绎交付说明

## 使用方式

1. 在手机底部或宽屏侧栏进入「演绎」，点击右上角「新建故事」。
2. 选择演员 A；演员 B 使用用户资料副本，可在本故事内修改，不会写回全局。
3. 填写开端、目标结局、轮数及双方模型。同一个 API 可以同时供两方使用。
4. 确认公开资料范围，按需勾选世界书与 A 的长期记忆。保存草稿不会请求模型。
5. 主动生成大纲、预览或编辑，再手动开始。B 始终标明为 AI 代演。

## 运行与恢复

- A 完成并保存后才请求 B；A+B 才计一轮，半轮恢复只补缺少的一方。
- 「暂停」完成正在请求的内容后停；「立即停止」取消当前请求并拒绝旧回包。
- 离开页面、后台和数据集切换会停止；返回前台、重启和恢复备份不会自动续演。
- 请求失败不会无限重试；格式修复最多一次，也计入配额。保存失败可重试保存，不重新请求完整内容。
- 请求预算为硬上限；没有提供 Token 用量的请求显示未知，不据此声称零成本。
- 已达成的结局需要最终阶段、完整轮次和正文证据，不能按百分比直接宣布完成。

## 编辑、事实与隐私

- 导演指令属于待执行约束，不会立即记成事实。支持一次手动接管 B 和最后一条 AI 正文重生成。
- 修改结局只重规划未来；编辑大纲保留过去阶段、当前阶段进度及事实摘要。
- 已验证事实可锁定；替换证据正文会使相关事实、场景和结局判定失效。
- 本故事数据独立于普通聊天记忆；来源角色后来上锁或删除，也不能绕过继承的隐私要求。
- TXT 默认只包含已保存正文和实际场景；目标与大纲需明确勾选，私设、推理、API 密钥和用量台账不导出。
- 支持正式正文收藏到回忆册；朗读只由用户手动触发，不驱动下一轮剧情。
