# Whisnya v1.5.6

## 更新内容

- 群聊支持编辑用户消息并重新发送；重发前提示将删除该条之后的消息，重新生成回复，并在需要时清除过时总结。
- 群聊复用普通聊天的紧凑消息操作栏，包含复制、删除、编辑重发和末条回复重新生成；生成期间禁止删除和修改消息。
- 普通聊天、群聊均支持图片附件，可单独发送图片，也可附带文字；发送前支持预览和移除，消息中的图片可点击放大。
- 图片按钮放在回复灵感右侧，点子、重新生成、编辑重发和发送按钮整体缩小。
- 每条消息最多附带 4 张图片，单张原文件不超过 20 MB；后台等比例缩放至最长边 1600 像素并转为 JPEG，原图保持不变。
- 图片随聊天保存，纳入备份恢复和媒体引用清理；剧情存档保留图片消息。

## 使用与安装

- 识图需要所选模型及其 OpenAI 兼容接口支持图像输入。选择图片本身不发起 AI 请求，点击发送后才交给当前模型处理；不支持时显示接口错误，不自动切换模型。
- Android ARM64 小包体，版本 1.5.6，内部版本码 2028（上个发布版为 2027）。
- 沿用原包名 com.mkdjj.whisnya 和历史签名（证书名称 Android Debug），可直接覆盖安装，更新前建议备份数据。
- 前一同源码功能包已由用户进行初步试用；定向检查覆盖窄屏布局、键盘保持、群聊编辑重发及图片存储和请求格式。未在开发环境连接真实识图 API 验证效果。
- 本次格式检查、静态分析及 Release 构建通过，已验证签名、版本码、包名、ARM64 架构及 debuggable=false。
