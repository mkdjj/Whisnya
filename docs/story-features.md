# 剧情、状态、回忆与系统语音

本次保持 `1.5.2+24`，沿用既有签名配置；不自动推送 GitHub 或发布 Release。

## 入口与默认值

- 聊天消息的“剧情与回忆”按钮（亦支持长按）：保存剧情存档、从这里分支、收藏单条或多选收藏。
- 聊天右上角更多：剧情存档、回忆册。设置中也有全局入口，原角色删除后仍可查看保留的快照。
- 设置中，“显示角色心声”之后是角色状态卡；显示、自动更新、加入上下文默认全部关闭。隐藏卡片不会删除已有状态。
- 角色编辑 → 折叠的“角色语音” → 系统音色与试听。系统语音、自动朗读、网络音色默认关闭；Android 与 Windows 分别配置。

## 剧情存档与分支

存档保存所选消息之前的正式正文及当时选中的候选，不是原聊天的动态引用。新分支是独立对话；不继承来源历史总结、来源当前对话记忆，默认也不使用角色共享长期记忆。当前角色设定、用户设定以及角色引用的世界书仍生效，世界书按分支自身的正文匹配。

分支的聊天设置可以明确允许共享长期记忆，会提示可能引入其他路线或未来信息。复制分支保留这一策略。删除原会话、修改候选不会修改已经保存的快照；删除存档不删除已有分支。原角色不存在时，存档可看但不能自动创建角色并继续。

旧消息及候选在加载时补齐稳定 ID 并保存；编辑保留消息 ID，新候选有新 ID。锚点摘要覆盖整个正式前缀，不包含心声、接口 reasoning 或显示设置。迟到的心声不会使正式前缀失效。

## 状态卡

每个会话分别保存情绪、双方关系、地点、当前动作。未知值不猜测；可以手动修改或锁定空值。切换候选/删除正文会回退到匹配当前前缀的状态，没有可靠记录时显示未知。

自动更新只在新正式回复成功保存后触发额外 AI 请求，使用该回复的 API；手动刷新使用当前选择的 API。可能产生额外费用，用量记为 `characterState`。输入仅含角色设定、旧状态/锁和最近最多 12 条正式正文，每条最多 1200 个字素；不发送回忆册或接口思考。开启页面、展开卡片、切换开关不触发刷新。

只有“显示状态卡”与“加入上下文”同时开启且存在已知字段时，才产生独立状态提示块。手动改动后到达的旧 AI 状态响应会丢弃，不覆盖手动结果。

## 回忆册与本地 PNG

可以选择 1–50 条不连续消息，按原顺序收藏。正文上限 100000 字素，超过时拒绝保存，不截断。标题、标签和备注可以编辑；正文、候选、心声和头像快照不会随着原聊天变化。

分享编辑器提供简洁对话、便签、暗色三种样式。姓名、头像、时间和心声默认不公开；心声还必须满足全局允许显示。永不分享接口 reasoning。正文和标题里的个人信息不会自动识别或抹除，请预览后自行确认。

本地 PNG 固定宽 1080px，每页高不超过 3840px，最多 12 页；长文本按字素分页，不压缩成无法阅读的小字。逐页生成并保存，取消/失败保留已经成功保存的页，报告部分完成。只保存文件，不自动发送到任何外部平台。

## 系统语音

采用 `flutter_tts 4.2.5` 调用设备现有引擎，不附带语音模型，不克隆声音，不生成音频文件，也不新增录音或通知监听权限。音色不存在时提示重新选择，不按另一平台的同名音色猜测。

只读当前候选的正式正文，跳过代码块和代码片段，去除 Markdown 标记但保留正常剧情文字。分段气泡只出现一个整条朗读控制。切换会话、编辑/删除/切换候选、进入后台或导入数据会停止朗读。自动朗读不用于 QQ 或剧场。

需要网络或网络属性未知的音色默认被阻止。手动朗读可以明确授权本次使用；全局网络开关表示允许系统语音服务商可能接收正文。设备能否离线使用、实际发音效果取决于安装的系统引擎及音色包。

## 存储、隐私与备份

新文件使用 schemaVersion 1，位于 `story/checkpoints`、`story/states`、`collection/items` 与 `collection/media`；不与已有长期记忆目录混用。全量备份仍为 schemaVersion 3，并附可选功能版本声明；老备份没有这些字段时按关闭/空内容恢复。

角色锁定会传播到其剧情存档与回忆册。即使角色后来删除，受保护快照仍需既有隐私密码。列表不显示受保护正文、标题、头像或搜索片段。这里是应用访问控制，不是磁盘内容加密；备份也含私密数据，需自行妥善保存。

存档、分支采用原子文件写入和索引最后发布，恢复日志仅清理本功能未发布的文件。清空聊天时状态参与已有清空事务，失败会回滚；不删除独立快照。删除角色额外提供“同时删除剧情存档和回忆册”选项，默认不勾选。

## 构建与验证说明

Flutter 位于 `.toolcache/flutter`。Windows 构建需要可发现的 NuGet CLI（语音插件的 C++/WinRT 构建依赖），本机使用经 Microsoft 签名验证的 `.toolcache/nuget/nuget.exe`，无需修改用户全局 PATH。[NuGet 官方安装说明](https://learn.microsoft.com/zh-cn/nuget/reference/nuget-exe-cli-reference)。Android 测试使用 `.toolcache/gradle-home` 避免非 ASCII 用户目录的 Java Worker 类路径问题。

测试日志保留在 `build/story-*.log`，ARM64 包及签名/哈希报告位于本次新建的 `dist/arm64-*` 目录。单元测试、真实临时目录备份往返、桌面编译不等同于真机试听或 Android 文件选择器验收；未连接真机时必须明确标注未验证。
